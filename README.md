# 闪电侠模组包：超级速度

一个面向 Minecraft 基岩版的闪电侠主题 Add-On。玩家可以注射黄色极速血清，获得「超级速度」能力，并通过调速手册调整奔跑速度。

> 当前说明对应 **v1.2.0**。本项目仍需在目标 Minecraft 客户端中进行实机测试；文中的速度为脚本目标值，不代表所有设备和世界中都能稳定达到。

## 功能特色

- **黄色极速血清**：首次进入世界时获得，使用后触发觉醒提示。
- **超级速度绑定物品**：觉醒后获得名为「超级速度」的能力物品。设计为背包锁定并在死亡后保留。
- **直接控制移动**：脚本通过玩家水平移动向量调整移动，不依赖速度药水效果。
- **速度调节手册**：打开手册后可将速度设置在 1%–100%。
- **蓝色高速残影**：奔跑时在身后生成短暂的蓝色虚影，并自动清理。
- **性能优化**：降低残影生成频率；没有玩家开启能力时，速度循环不执行玩家移动处理；玩家离开时清理临时状态。
- **作者信息**：游戏内手册包含作者与 GitHub 信息。

## 速度设定

| 设置 | 脚本目标值 |
|---|---:|
| 速度调节范围 | 1%–100% |
| 100% 目标速度 | 约 4.5 格/游戏刻，理论约 90 格/秒 |
| 短时冲刺目标 | 最高约 5.6 格/游戏刻，理论约 112 格/秒 |

以上换算以 20 游戏刻/秒为前提。实际移动距离会受到游戏刻率、设备帧率、碰撞、地形、服务器性能及区块加载影响，不能保证达到理论数值。高速移动可能导致区块加载延迟、穿模、卡顿或其他异常，请从较低速度开始测试。

## 游戏内使用方法

1. 导入 `.mcaddon` 文件。
2. 在世界设置中启用本项目的行为包（BP）和资源包（RP）。
3. 进入世界后，首次进入时会获得黄色极速血清和闪电侠调速手册。
4. 使用黄色极速血清，觉醒并获得「超级速度」能力物品。
5. 使用「超级速度」物品开启或关闭能力。
6. 按住游戏内冲刺键奔跑，触发高速移动。
7. 使用「闪电侠调速手册」打开设置界面，调整 1%–100% 的速度。

## 安装与兼容性

- **目标平台**：Minecraft Bedrock Edition
- **最低目标版本**：1.20.0
- **Add-On 结构**：行为包（BP）+ 资源包（RP）
- **脚本依赖**：
  - `@minecraft/server`：`1.2.0`
  - `@minecraft/server-ui`：`1.0.0`

BP 的 manifest 声明了对 RP 的 UUID 和版本依赖。导入后请在世界设置中确认 BP 与 RP 均已启用。

### 更新旧版本

如果此前安装过旧版，建议先在测试世界中移除旧 BP/RP，再导入新版并重新启用两个包。重要世界请先备份。

## 性能与预加载说明

本项目采用减少无效脚本处理、降低残影生成频率、及时移除残影实体等方式控制额外负载。

Minecraft Bedrock 1.20.0 的稳定 Script API 并没有适合本项目、可安全动态预加载玩家前方区块的通用接口。因此本版本没有通过持续创建 `tickingarea` 来强制加载区块，以免增加常驻区块数量和内存占用。高速移动时仍可能遇到区块尚未加载的情况。

## 已知限制与测试状态

- 速度数值属于脚本目标值，尚不能视为所有设备上的实测成绩。
- 高速移动的实际效果受游戏引擎、地形、碰撞和区块加载影响。
- 绑定物品使用基岩版物品锁定及死亡保留机制；请在目标游戏版本中确认锁定标志、丢弃限制和死亡保留行为。
- 蓝色残影的显示效果、资源包兼容性及长期运行稳定性仍建议在实际设备上测试。
- 本项目不保证在所有旧版基岩版客户端中兼容。虽然目标最低版本为 1.20.0，但不同小版本的脚本 API 行为可能存在差异。
